# QuestBridge XR — black diamond-tufted RGB headboard

This update changes **only the existing headboard** to follow the supplied 4 EVER WINNER LED bed-frame reference.

## Headboard design

- Black, softly padded faux-leather / PU-style upholstery.
- A regular field of raised diamond-shaped cushions, not a single oversized flat cushion and not vertical channels.
- Small polished crystal-look tuft buttons at the diamond intersections.
- A matching padded black outer frame with softened corners.
- A controllable RGB light strip integrated into the headboard perimeter. Its color is driven by the existing **Environment → LED Colors → Headboard Glow** zone.

The reference listing describes a PU-upholstered diamond-tufted headboard with crystal-style buttons and color-controllable LED lighting:
[4 EVER WINNER Queen Size LED Bed Frame at Walmart](https://www.walmart.com/ip/4-EVER-WINNER-Queen-Size-LED-Bed-Frame-with-Headboard-Upholstered-Platform-Bed-Frame-with-LED-Lights-Diamond-Tufted-Headboard-and-Footboard-Black)

## What stays exactly as it was

- Bed platform, rails, legs and foot end. No footboard redesign or added footboard lighting.
- Mattress, fitted sheet, original sleep pillows, accent cushions, duvet and throw.
- Bed position, collision footprint, bedside furniture, TV, monitor, window and all other room objects.
- Head tracking, turning, locomotion, wall light-switch interaction and the existing LED color-control UI.

## Blender project

\`arc_upholstered_bed.blend\` is generated by the Blender 4.5.15 workflow from \`arc_upholstered_bed_editable.glb\`. Each diamond pad, button and frame component is a separately named editable mesh. The runtime GLB continues to merge meshes by material for mobile rendering efficiency.

To regenerate the mesh from the repository root:

\`\`\`bash
QBX_BED_OUTPUT_DIR=art/bed \\
QBX_BED_RUNTIME_GLB=quest-client/app/src/main/assets/models/arc_upholstered_bed.glb \\
python tools/generate_bed_asset.py
\`\`\`

Then, with Blender 4.5.15 or newer installed:

\`\`\`bash
blender --background --python tools/blender_import_bed.py -- \\
  --source art/bed/arc_upholstered_bed_editable.glb \\
  --output art/bed/arc_upholstered_bed.blend \\
  --render-dir art/bed/renders
\`\`\`
