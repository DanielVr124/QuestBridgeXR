# QuestBridge XR — single-panel recessed-glow headboard

This update changes **only the existing headboard**.

## Headboard design

- One continuous charcoal upholstered panel across the headboard.
- A gently crowned padded face with slightly softened edges; no diamond pattern, buttons, vertical channels or segmented cushions.
- Nested inner and outer frame lips create a recessed perimeter lighting channel.
- The RGB glow sits behind the front edges of those lips. From a low lying-down angle, the LED emitter itself should be hidden and only its reflected glow should show; looking straight at the headboard, the recessed light detail remains visible.
- The native renderer supplies the colour-changing glow. No exposed LED tape or bulb geometry is added.

## What stays exactly as it was

- Bed platform, rails, legs and foot end.
- Mattress, fitted sheet, original sleep pillows, accent cushions, duvet and throw.
- Bed position, collision footprint, bedside furniture, TV, monitor, window and all other room objects.
- Head tracking, turning, locomotion and all unrelated controller interactions.
- Existing environment lighting controls and their per-zone colour settings.

## Blender project

`arc_upholstered_bed.blend` is generated by the Blender 4.5.15 workflow from `arc_upholstered_bed_editable.glb`. The single upholstered panel and its nested frame lips remain separately named editable meshes. The runtime GLB continues to merge meshes by material for mobile rendering efficiency.

To regenerate the mesh from the repository root:

```bash
QBX_BED_OUTPUT_DIR=art/bed \
QBX_BED_RUNTIME_GLB=quest-client/app/src/main/assets/models/arc_upholstered_bed.glb \
python tools/generate_bed_asset.py
```

Then, with Blender 4.5.15 or newer installed:

```bash
blender --background --python tools/blender_import_bed.py -- \
  --source art/bed/arc_upholstered_bed_editable.glb \
  --output art/bed/arc_upholstered_bed.blend \
  --render-dir art/bed/renders
```
