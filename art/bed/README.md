# QuestBridge XR — diamond-tufted LED bed

This original bed model is made for the existing neon gaming bedroom. Its design follows the user's visual references: a black upholstered platform with a diamond-tufted headboard and matching footboard, a silver-grey framed edge, and substantial quilted side-sleeper pillows with real box-gusset depth.

## Model design

- Black upholstered headboard with a broad, softly padded back, individual diamond-shaped tuft pads, recessed lattice points, and small silver-grey pull buttons.
- Raised silver-grey perimeter trim around the headboard, with an inset LED reveal. The footboard has a matching diamond-tufted face, grey piping and a matching LED edge. Both LED reveals follow the existing bedside RGB remote's red, green, blue, white, purple and cyan presets.
- Two full-size side-sleeper pillows with a rounded-rectangle footprint, genuinely deep separate box-gusset sidewalls, a domed/fluffy cotton crown, softly eased corners, raised perimeter welt and diamond-quilt stitching that follows the puffed surface. The top, gusset and underside are separate named meshes; the pillows sit slightly propped against the headboard.
- Smaller graphite accent pillows remain behind the white pillows; the mattress, fitted cotton sheet, folded graphite duvet, and draped midnight-blue throw retain their existing material palette.
- The floating black platform, side rails, bedside cabinets, RGB remote, bed anchor, TV, window and collision footprint remain unchanged.
- Eight mobile-friendly runtime material groups with embedded 512 px textile textures. The editable source preserves separately named headboard diamonds, tuft buttons, trims, pillows, seams and other components.

## Reference direction

The design is original geometry, using the linked products only for broad visual cues:

- [The Big One Quilted Side Sleeper Pillow at Kohl's](https://www.kohls.com/product/prd-3230958/the-big-one-quilted-side-sleeper-bed-pillow.jsp?skuid=60127428) — thick boxed side gusset, quilted top, piping and softly rounded but defined corners.

No third-party 3D bed or pillow mesh is used.

## Dimensions and coordinates

All dimensions are metres. X is width, Y is up and Z is bed length. The headboard is at negative Z. The overall assembly stays centred on the original bed anchor and within its existing back-right room placement. The bedside furniture, remote, TV, window and collision footprint retain their previous positions.

## Blender project

`arc_upholstered_bed.blend` is generated by the Blender 4.5.15 headless workflow from `arc_upholstered_bed_editable.glb`. It keeps the detailed mesh parts in a dedicated `BED MODEL | editable named parts` collection and the studio floor, area lights and reviewer cameras in a separate `STUDIO | render-only setup` collection. Fabric images are packed into the Blend file. Four Cycles views are rendered for review.

To regenerate the mesh and texture source from the repository root:

```bash
QBX_BED_OUTPUT_DIR=art/bed \
QBX_BED_RUNTIME_GLB=quest-client/app/src/main/assets/models/arc_upholstered_bed.glb \
python tools/generate_bed_asset.py
```

Then, with Blender 4.5.15 or newer installed:

```bash
blender --background --python tools/blender_import_bed.py -- \
  --source art/bed/arc_upholstered_bed_editable.glb \
  --output art/bed/arc_upholstered_bed.blend \
  --render-dir art/bed/renders
```
